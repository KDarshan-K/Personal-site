FarmVista was built by team TwoOne for IEEE HackaPhasia 2025. The project explored using government datasets to forecast local market demand and help farmers make more informed crop-planning decisions.

The prototype included a Flutter mobile interface and a Random Forest model for soil NPK-related prediction.
