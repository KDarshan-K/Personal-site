- **Autonomous Agentic Systems & RAG:** Designing multi-agent pipelines with LangGraph featuring bounded critic/revision feedback loops, hybrid semantic vector search (FAISS, Sentence Transformers, TF-IDF cosine similarity), and grounded LLM synthesis.
- **Backend Engineering & Data Infra:** Architecting asynchronous REST services with FastAPI, geospatial indexing and aggregation pipelines with MongoDB, and lightweight, reactive UIs with HTMX.
- **Applied Machine Learning & Quant:** Engineering macroeconomic predictive models with XGBoost, evaluating financial strategies through rigorous backtesting and Sharpe ratio analysis, and experimenting with deep visual recognition under adversarial attack scenarios (FGSM, PGD).
- **Cloud & DevOps Automation:** Continuous integration and deployment via GitHub Actions, containerization using Docker, and research into reinforcement learning for dynamic cloud compute resource allocation.
