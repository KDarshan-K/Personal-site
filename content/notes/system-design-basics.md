## Start with requirements

Separate functional requirements from non-functional requirements. Estimate traffic and storage before selecting technologies.

## Make trade-offs explicit

For each decision, record the constraints, alternatives, expected bottlenecks, and operational costs. A diagram is useful only when it explains a decision.
